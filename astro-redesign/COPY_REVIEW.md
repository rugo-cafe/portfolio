# copy review · portfólio
rascunho para revisão autoral, 12/10/2026. **nenhuma frase é definitiva.**

## critérios editoriais
- comece pelo observável, não por um adjetivo.
- evite a primeira pessoa grandiosa e a poesia performática.
- deixe que palavras do universo do autor (rádio, arquivo, navegador, escrita, código, som, imagem) apareçam quando fizerem sentido.
- a página deve continuar comunicando trabalho real; poesia não substitui descrição de projeto.
- uma frase deve poder ser lida em voz alta sem constrangimento.

## passagens para revisar uma a uma

> trabalho com desenvolvimento web e interfaces. também mantenho um projeto de rádio, arquivo e curadoria musical.

**experimental (na branch)**
> escrevo código para coisas que se usam, se escutam ou se guardam.

**contexto**
> sou vitor. trabalho com interfaces e desenvolvimento web. como rugo, faço rádio e reúno transmissões no coisas bonitas, na hkcr. aqui essas linhas acabam se cruzando.

- [ ] a voz parece minha?
- [ ] “escrevo código” comunica suficientemente a atuação em design?
- [ ] “aqui essas linhas acabam se cruzando” soa afetado?

### 07 / sobre
**atual na produção**

**outra hipótese**

Essa última é **apenas exploratória** e não deve ir ao ar sem contexto ou aprovação. Pode soar pretensiosa; considerar se um fato observável funciona melhor.

- [ ] escolher texto baseado em experiência real, não em arquétipo de artista.

Esse trecho é funcional e talvez **não precise de poesia**.
